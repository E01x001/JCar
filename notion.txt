자신이 요청한 것에 대해 어떻게 상태가 변화했는지 확인할 수 있고, 재신청이 가능하고, 상담 신청했던 걸 삭제할 수 있도록 했음. 

이후 가장먼저 발생했던 문제는, 어드민 화면에서 메모 및 시간 조절 제안을 남기기위해 popup 버튼을 눌렀을 때, popup에서 백그라운드를 어둡게 보여주기 위한 창과, 앞에 보여야하는 팝업창의 순서가 뒤죽박죽으로 섞여있어 버튼이 제대로 눌리지 않고 글자가 잘 안보이는 문제가 존재했음.

현재 해당 문제는 제대로 해결하지 못하고 둔 상태.

문제2. 만약 시간 조정을 위해 관리자가 새로운 시간을 제안하려고 하면 오류가 발생.

문제3. 초기 차량에 대한 상담을 신청하고 보류를 눌렀다가 거절을 할 경우 상태는 제대로 바뀌는데 이게 데이터베이스에 제대로 적용이 안되는 것인지 차량 상세탭과 관리자 메인화면에서는 거절됨으로 뜨지 않고 여전히 보류로 뜸.

- 해당 문제는 ConsulationStatus와 일반 Status가 중복해서 존재하며 어떤 화면에서는 status를 참조하고 어떤 화면에서는 consulationstatus를 참조하기에 발생했던 문제. 현재 문제의 원인을 알아 조정중에 있으나 내가 알지 못하는 스크린 또는 코드에서 Status가 사용된 곳이 있었고 이에 대해 수정중에 있음
- 아직 수정이 진행중이기에 현재 유저 권한으로 마이페이지에 들어갈 경우 status라는 데이터가 존재하지 않는데 status를 참조하기에 발생하는 오류가 있음.

문제4. 차량들의 상태를 보니 데이터를 제대로 읽어오지 못하는 것인지 Consulation request 에 대한 필드 중 아무것도 들어가지 않고 null 상태인 필드가 존재. 해당 필드 내용을 확인하고 수정이 필요함.

문제 5. 차량 상담 신청 내역을 유저측에서 취소했음에도 불구하고 다시 신청을 하려고 할 때 해당 차량에 대해 이미 신청내역이 존재한다고 뜨며 중복 신청 문제로 상담 신청이 불가능해짐. 해당 로직의 경우 중복신청을 가능하게 할 것인지, 신청을 취소할 때마다 데이터베이스에서 삭제해주는 방법으로 진행할 것인지를 고려해볼 필요가 있음. 무엇이 되었든, 보편적으로 사용하면서 보안성을 지킬 수 있는 방안을 선택해야함.

문제 6. 상담 상태 변경과 관련하여 어드민이 일정 탭에서도 상담상태를 변경할 수 있는데 이곳에서는 승인 또는 거절만 존재하며 이는 분명 stauts와 consulation status 둘 중 status를 참고하고있을 것으로 생각되기에 수정이 필요할 것 같음. → 알고보니 status와 consulation status와 관련된 내용이 아니었고, theme 에 관련된 내용이었음. 따라서 관련이 없는 내용이었고 현재 해결한 상태.
